# Перевірка типографіки й доступності — 2026-11-05

## Реалізовано

- Основний текст: 1.125rem (18px при стандартному корені 16px).
- Кнопки, навігація й поля: 1rem (16px); допоміжні підписи: від .875rem (14px).
- Прибрано зменшення до 6–12px у мобільних правилах; локальні шрифти мають кириличні набори.
- Підсилено контраст приглушених текстів, placeholder, фокуса та підписів на фотографіях.
- Мобільне меню працює як native dialog із власною кнопкою закриття, Escape та керуванням фокусом. Фон виключений із дерева доступності під час відкриття.
- Header вимірюється ResizeObserver; відступи враховують реальну висоту після перенесення мовних кнопок або збільшення тексту.
- Мобільне фото hero заповнює висоту секції через object-fit: cover; пропорції збережено, кадрування утримує ковбасу й тарілку.
- Збережено останні upstream-зміни d6d1d23: українська мова за замовчуванням, PL/УКР і зображення Вершкової.

## Фактично виконано в Chrome

- Українська й польська версії на 320, 390, 768, 1024, 1440, 1920 CSS px: жодного видимого текстового елемента менше 14px; після виправлення tablet-локатора жодних рядків поза viewport і горизонтального переповнення документа.
- Збільшення тексту коренем 200% на 320px: body 36px, обидві мови без рядків за межами viewport; українське модальне вікно має scrollWidth = clientWidth = 268px.
- Збільшені інтервали на українській сторінці 390px: line-height 1.5, letter-spacing .12em, word-spacing .16em, відступ після абзаців 2em — без горизонтального переповнення чи рядків поза viewport.
- Меню: native :modal, фокус у кнопці закриття, Escape; дерево доступності містить лише меню. Axe для відкритого меню: 0 violations, 0 incomplete.
- Відкриття Вершкової після UK → PL → UK: правильні назва, опис, alt та assets/products/vershkova.webp.
- Фото Вершкової збережено в модальному вікні, текст переноситься при збільшенні.
- Reduced motion, видимість фокуса, локальні файли та JavaScript syntax перевірено. Виконано node --check для п’яти JS-файлів і git diff --check.
- Збережено accessibility-mobile-390.jpg та accessibility-desktop-1440.jpg.

## Автоматичний скан

Axe-core 4.10.3, теги wcag2a, wcag2aa, wcag21aa, wcag22aa. До змін: 11 вузлів із недостатнім контрастом. Фінальний скан сторінки: 0 violations, 29 passes. 49 вузлів залишилися incomplete для color-contrast через псевдоелементи, фотографії або накладання; це не є автоматично підтвердженим проходженням контрасту. Див. accessibility-before.json та accessibility-after.json.

Окремий розрахунок базових кольорів продуктових карток дає мінімум 4.82:1 для світлого тексту й 5.65:1 для темного. Підписи поверх фото отримали суцільну підкладку, великі заголовки — затемнення фотографії. Декоративні елементи та зображення етикеток не є основним текстом сторінки.

## Межі перевірки

Це виправлення та браузерний аудит, а не сертифікація відповідності всім WCAG. Safari, Firefox, фізичні пристрої й VoiceOver/NVDA не тестувалися. У Chrome були повідомлення IO error від розширення блокування реклами/його бази даних; їх не прийнято за чисту консоль застосунку. Функціональні перевірки завершилися.
