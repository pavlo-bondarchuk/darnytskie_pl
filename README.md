# Дарницькі вироби

Двомовний сайт-каталог для польського ринку на GitHub Pages. Статичні HTML, CSS і JavaScript без етапу складання. Для локального перегляду запустіть `python3 -m http.server 8765` у корені репозиторію та відкрийте http://localhost:8765/.

## Вміст

- `index.html` містить головну сторінку, ідеї подачі та базові українські тексти. Польські відповідники зберігаються в атрибутах `data-pl`, `data-pl-alt` і `data-pl-aria`.
- `js/i18n.js` перемикає мову та метадані й запам’ятовує вибір. Початкова мова українська.
- `js/products.js` містить десять продуктів, оригінальні етикетки, двомовні ідеї подачі, фільтри та розгортання картки всередині каталогу. Кнопки в ідеях подачі відкривають відповідний продукт.
- `css/style.css` описує шрифти, фірмові кольори, мобільну й десктопну композицію та режим зменшеного руху.
- `js/main.js` керує меню й навігацією з клавіатури.
- `js/stores.js` відображає лише підтверджені точки з назвою, містом і адресою. Коли список порожній, на сторінці видно короткий статус. Для наповненого списку працюють фільтрація та посилання на Google Maps.

Перед завантаженням `js/stores.js` можна задати масив `window.STORES`. Кожен запис містить `name`, `city`, `address` та булеве поле `verified`. Для пошуку міст польські діакритичні знаки необов’язкові.

## Матеріали бренду

У сітці каталогу використано десять ШІ-ілюстрацій подачі з `assets/products/serving/`. Розгорнута картка показує оригінальний дизайн етикетки. Гастрономічні зображення на першому екрані й у блоці подачі ілюстративні. Походження матеріалів задокументовано в [ASSETS.md](ASSETS.md).

Підтверджених адрес і контактів наразі немає. Для комерційного запуску потрібно погодити фінальні тексти й зображення, надати торгові точки та вирішити, коли дозволити індексацію. До того часу діє `noindex, nofollow`.
