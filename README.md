# Darnytskie — frontend prototype

Односторінковий frontend-прототип українського бренду для польського ринку. Українська — початкова мова; перемикач доступний польською. HTML, CSS і Vanilla JavaScript; без backend, CMS і складання.

## Запуск

```sh
cd /Users/mac/Documents/radio-privoz/darnytskie
python3 -m http.server 8765 --bind 127.0.0.1
```

Відкрити http://127.0.0.1:8765. Встановлення npm-пакетів не потрібне.

## Архітектура

- `index.html`: семантичні секції та native dialog для мобільного меню.
- `css/`: токени, композиція, адаптивність і reduced motion.
- `js/i18n.js`: українська за замовчуванням та польська локалізація інтерфейсу.
- `js/products.js`: продуктові дані, мозаїка та розгортання вибраної картки на всю область каталогу без попапа.
- `js/stores.js`: локатор і набір підтверджених торгових точок.
- `js/main.js`: навігація, стан header та мобільне меню.
- `js/animations.js`: GSAP/ScrollTrigger з fallback без анімацій.
- `assets/`: оригінальні етикетки й логотип, upstream-зображення одного продукту з неперевіреною фотопоходженням, ілюстративні hero/table зображення та локальні шрифти й бібліотеки.

Клік по картці плавно розгортає її всередині каталогу крізь кругову маску; решта карток послідовно зменшуються та зникають. Закриття або Escape відтворює рух навпаки й повертає початкову мозаїку. На мобільному висота розгорнутого товару обмежена екраном.

## Межі прототипу

Оригінальний логотип та друковані етикетки взято з бренд-папки Google Drive. Етикетки демонструють айдентику, а не фотографії готового товару. `assets/products/vershkova.webp` додано upstream-зміною `d6d1d23`; це зображення ковбаси з маркуванням «Вершкова», але його джерело та автентичність фото не перевірено незалежно. Hero і table зображення — ілюстрації, створені ImageGen. Склад, харчова цінність, вага та умови зберігання не затверджені для цього сайту. Джерела зображень та перелік потрібних матеріалів: `ASSETS.md`.

Manrope та Oswald підключені локально з ліцензійними файлами OFL; каталог зберігає обидві мовні версії інтерфейсу. Hero/table ілюстрації не є фотографіями продукції бренду.

Реальні адреси магазинів, телефон, email і соціальні профілі не надані. Локатор містить порожній набір даних і чесно повідомляє про demo-state. Контакти позначено як такі, що потребують заповнення. Жодна форма не імітує надсилання.

Для підключення магазинів заповнити `window.STORES` у `js/stores.js` масивом записів такої форми:

```js
window.STORES = [
  {
    name: "Nazwa punktu",
    city: "Warszawa",
    address: "Potwierdzony adres",
    verified: true
  }
];
```

`name`, `city` і `address` — текст; `verified` — булеве значення. Пошук зіставляє місто, назву й адресу без урахування регістру та польських діакритичних знаків. Посилання на Google Maps з'являється лише для запису з `verified: true` і непорожньою адресою. Для WordPress слід перенести секції до шаблону, дані — до відповідних полів, а селектори інтерфейсу зберегти.

## Перед публічним запуском

Замінити тимчасові ілюстрації та неперевірене низькороздільне upstream-зображення на затверджені матеріали бренду, затвердити українські й польські назви та описи, заповнити перевірені контакти й адреси, додати фінальне Open Graph-зображення, прибрати `noindex` після погодження. Локальний прототип не змінює production-сайт.
