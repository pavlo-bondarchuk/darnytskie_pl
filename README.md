# Darnytskie — frontend prototype

Односторінковий польськомовний дизайн-прототип. HTML, CSS і Vanilla JavaScript; без backend, CMS і складання.

## Запуск

```sh
cd /Users/mac/Documents/radio-privoz/darnytskie
python3 -m http.server 8765 --bind 127.0.0.1
```

Відкрити http://127.0.0.1:8765. Встановлення npm-пакетів не потрібне.

## Архітектура

- `index.html`: семантичні секції й native dialog.
- `css/`: токени, композиція, адаптивність і reduced motion.
- `js/products.js`: продуктові дані, мозаїка та модальне вікно.
- `js/stores.js`: локатор і набір підтверджених торгових точок.
- `js/main.js`: навігація, стан header та мобільне меню.
- `js/animations.js`: GSAP/ScrollTrigger з fallback без анімацій.
- `assets/`: оригінальні бренд-матеріали, ілюстративна фотографія й локальні бібліотеки.

## Межі прототипу

Оригінальний логотип та друковані етикетки взято з бренд-папки Google Drive. Етикетки демонструють айдентику, а не фотографії готового товару. Склад, харчова цінність, вага та умови зберігання не затверджені для цього сайту.

Гастрономічні зображення створено ImageGen як тимчасові ілюстрації. Вони не є фотографіями продукції бренду. Джерела й список потрібних матеріалів: `ASSETS.md`.

Реальні адреси магазинів, телефон, email і соціальні профілі не надані. Локатор містить порожній набір даних і чесно повідомляє про demo-state. Контакти позначено як такі, що потребують заповнення. Жодна форма не імітує надсилання.

Для підключення магазинів заповнити `window.STORES` у `js/stores.js` масивом записів такої форми:

```js
window.STORES = [
  {
    name: "Nazwa punktu",
    city: "Warszawa",
    address: "Potwierdzony adres",
    verified: true
  }
];
```

`name`, `city` і `address` — текст; `verified` — булеве значення. Пошук зіставляє місто, назву й адресу без урахування регістру та польських діакритичних знаків. Посилання на Google Maps з'являється лише для запису з `verified: true` і непорожньою адресою. Для WordPress слід перенести секції до шаблону, дані — до відповідних полів, а селектори інтерфейсу зберегти.

## Weryfikacja

Перевірено у Chrome 4 листопада 2026 року: 5 контрольних ширин, 8 модальних вікон, мобільне меню, якірні переходи, demo-пошук і reduced motion. Звіт: `qa/VERIFICATION.md`; скриншоти: `qa/desktop-1440.jpg` та `qa/mobile-390.jpg`.

## Перед публічним запуском

Замінити ілюстрації на оригінальні продуктові фото, затвердити польські назви й описи, заповнити перевірені контакти та адреси, додати фінальне Open Graph-зображення, прибрати `noindex` після погодження. Локальний прототип не змінює production-сайт.
